# Jeremy – מצלמת דרך לטלפון (V25)

אפליקציית Android (Kotlin + Jetpack Compose + CameraX + Media3) שהופכת את הטלפון למצלמת דרך שממשיכה לצלם ברקע.

## פתיחה ובנייה
1. פתח את התיקייה `Jeremy` ב־Android Studio (Ladybug ומעלה).
2. Android Studio יוריד את ה־SDK והתלויות אוטומטית (Gradle 8.14.3, AGP 8.7.3, Kotlin 2.0.21).
3. `Run ▶` על מכשיר אמיתי (Android 8.0 / API 26 ומעלה). אמולטור לא מתאים לבדיקת מצלמה/חיישנים.
4. לבניית APK: `Build → Build App Bundle(s)/APK(s) → Build APK(s)`.

## ארכיטקטורה – למה זה יציב
| רכיב | אחריות |
|---|---|
| `service/DashcamService` | **הבעלים היחיד של CameraX.** Foreground Service מסוג `camera` (+`microphone`), WakeLock, Rolling Buffer, אירועים, ייצוא, חיישנים, קול, התראה וכפתור צף. |
| `core/DashcamController` | מצב משותף (StateFlow) בין ה־UI לשירות. ה־UI שולח פקודות בלבד. |
| `ui/screens/CameraScreen` | **לא פותח מצלמה.** רק מציע `SurfaceProvider` לשירות ומסיר אותו ב־`ON_STOP` – כך אין לעולם מצב שבו Activity ו־Service פותחים מצלמה יחד. |
| `core/EventExporter` | מחבר את הקטעים ל־**MP4 אחד רציף** עם Media3 Transformer, וצורב לתוך הפיקסלים את `Jeremy` ואת התאריך/שעה. |
| `service/FloatingButton` | כפתור צף (WindowManager overlay) שבבעלות השירות – מופיע כשהאפליקציה ברקע, נעלם רק בכיבוי. |

### Rolling Buffer ו־Pre-Event
- המצלמה מקליטה ברציפות קטעים של 5 שניות לתיקייה פנימית; קטעים ישנים מהחלון (5/10/15/30/60 ש׳) נמחקים.
- בלחיצה על "שמור אירוע" נשמר זמן האירוע; ההקלטה ממשיכה **עד שעוצרים** (אין סיום אוטומטי).
- בעצירה: הקטע הנוכחי נסגר, נבחרים כל הקטעים מ־`זמן האירוע − X שניות` ועד העצירה, הקטע הראשון נחתך בדיוק, והכול מיוצא לקובץ אחד.
- שעון התאריך/שעה בסרטון מחושב מזמן הצילום האמיתי של כל פריים – לא מזמן הייצוא.

### דרכי הפעלת אירוע
כפתור במסך המצלמה · כפתור צף · כפתור בהתראה · פקודה קולית · זיהוי מכה (חיישן תאוצה) · זיהוי חכם מקומי בתמונה (`MotionAnalyzer`, מוכן להחלפה במודל AI בעתיד).

## בדיקות שחובה להריץ לפני הפצה
- [ ] הפעל נסיעה → צא ל־Waze/Spotify 30 דק׳ → שמור אירוע מהכפתור הצף → הסרטון מתחיל ~15 ש׳ לפני הלחיצה.
- [ ] כיבוי מסך 10 דק׳ בזמן נסיעה → שמירת אירוע מההתראה.
- [ ] כניסה/יציאה ממסך המצלמה 50 פעם בזמן אירוע פעיל – בלי קריסה ובלי קטיעת ההקלטה.
- [ ] סיבוב מכשיר במסך המצלמה (כפתור עובר לימין) ובשאר המסכים (פריסה רגילה).
- [ ] לחיצה ארוכה על הכפתור הצף / "כבה מצלמה" בהתראה → מצלמה, חיישנים, התראה וכפתור צף נעלמים.
- [ ] שיתוף ל־WhatsApp → קובץ אחד, עם `Jeremy` ותאריך/שעה צרובים.
- [ ] אירוע נעול לא נמחק כשמגיעים למכסת האחסון.
- [ ] החלפת רזולוציה/FPS/שמע באמצע נסיעה.

## מגבלות ידועות
- בין קטעי ה־buffer יכול להיות פער של עשרות מילישניות (CameraX לא תומך בפיצול רציף לקבצים).
- בחלק מהמכשירים זיהוי קולי והקלטת שמע לא עובדים יחד (המיקרופון תפוס).
- Android לא מאפשר לפתוח מצלמה מהרקע אחרי שהמערכת הרגה את השירות; לכן מומלץ לבטל אופטימיזציית סוללה (יש כפתור במסך ההדרכה/הגדרות).
- הפרויקט נכתב ללא גישה ל־Android SDK בסביבת היצירה, כך שלא עבר קומפילציה – ייתכנו תיקוני קומפילציה קטנים בפתיחה הראשונה ב־Android Studio.

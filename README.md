# Shomer – מצלמת גוף לטלפון

אפליקציית Android (Kotlin + Jetpack Compose + CameraX + Media3) שהופכת טלפון שנלבש על החזה למצלמת גוף.

## הרעיון
- **משמרת = כוננות:** המצלמה עובדת ברקע ושומרת רק את X השניות האחרונות (pre-record). שום דבר לא נשמר.
- **תיעוד:** לחיצה אחת (כפתור, הגברת שמע, כפתור צף, התראה, ניעור, קול) מתחילה תיעוד. כדי לעצור **מחזיקים** – מכה מקרית לא עוצרת ראיה.
- **מצב כיס:** מסך שחור בבהירות מינימלית שמתעלם מנגיעות; הגברת שמע עדיין עובדת; הקשה כפולה יוצאת.
- **רטט במקום מסך:** ארוך = התחיל, 2 קצרים = נעצר, 3 קצרים = נשמר.
- **Man-down:** נפילה (נפילה חופשית/מכה → שינוי זווית הגוף → שכיבה ללא תזוזה) מתחילה תיעוד, ואופציונלית ספירה לאחור וחיוג.
- **ראיה חתומה:** כל סרטון מקבל SHA-256 בשמירה + קובץ `.sha256` לידו, נשמר נעול, ובדיקת שלמות במסך התיעוד.
- **חותמת צרובה:** `SHOMER • <שם/תג>` / תאריך-שעה-אזור זמן / קואורדינטות, בפינה העליונה.

## ארכיטקטורה
| רכיב | אחריות |
|---|---|
| `service/BodycamService` | הבעלים היחיד של CameraX; buffer, תיעודים, ייצוא, חיישנים, התראה, כפתור צף |
| `core/ShiftController` | מצב משותף (StateFlow) בין ה־UI לשירות |
| `core/detect/FallAlgorithm`, `ShakeAlgorithm` | זיהוי נפילה וניעור – קוד טהור עם בדיקות יחידה |
| `core/Exporter` | חיבור הקטעים ל־MP4 אחד וצריבת החותמת (Media3 Transformer) |
| `core/Evidence` | SHA-256, קובץ `.sha256`, בדיקת שלמות |

בנייה: GitHub Actions (`.github/workflows/build-shomer.yml`) – בדיקות יחידה, AAB ו־APK לענף `apk-shomer`.
